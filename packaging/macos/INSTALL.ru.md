# tuntop для macOS — установка

tuntop — VPN-клиент в терминале (как Happ, но в окне Терминала) на основе
Xray. Это тестовая сборка до первого релиза: если что-то не так, напишите
тому, кто дал архив, — с текстом ошибки и примерным временем.

В архиве программа для Apple Silicon и Intel, установщик сам выберет
нужную. Понадобится **ссылка на подписку** вашего VPN-провайдера (та же,
что вы вставляете в Happ).

## 1. Проверьте версию macOS

Нужна **macOS 13 Ventura или новее**: меню  → «Об этом Mac». Или в
Терминале:

```bash
sw_vers -productVersion
```

На macOS 12 и старше tuntop не запустится.

## 2. Распакуйте и установите

1. Скопируйте архив на Mac (AirDrop, флешка) и откройте его двойным
   щелчком: рядом появится папка `tuntop-…-macos`.
2. Откройте Терминал и перейдите в эту папку. Проще всего набрать `cd `
   (с пробелом) и перетащить папку из Finder в окно Терминала, затем
   Enter.
3. Запустите установщик (спросит пароль администратора):

   ```bash
   sudo bash install-macos.sh
   ```

Что он делает: кладёт `tuntop` и `tuntopd` в `/usr/local/bin`, ставит
службу (запускается вместе с системой, VPN при этом выключен),
уведомления для вашего пользователя и скачивает базы geoip/geosite с
GitHub в `/usr/local/share/tuntop`. Сеть при установке не меняется.

Проверка: `tuntop version` — номер версии; `tuntop` — откроется
интерфейс, в заголовке «○ ВЫКЛ».

## 3. Добавьте подписки

В интерфейсе `tuntop`: **4** → **a** → вставить ссылку (**Cmd+V**) →
Enter. Или в Терминале: `tuntop sub add <ссылка>`.

Этот Mac для провайдера — **новое устройство**: tuntop передаёт
идентификатор устройства, как Happ. Если у подписки исчерпан лимит
устройств, вместо серверов придёт сообщение провайдера (например,
«Превышен лимит устройств») — освободите место в личном кабинете
провайдера и добавьте подписку снова.

## 4. Включите VPN

1. **Выключите другие VPN** (Happ и т. п.): с ними tuntop не подключится.
2. В `tuntop` выберите сервер стрелками → **Enter**. Или `tuntop on <номер
   или часть названия>`.
3. Проверка: `tuntop status` — «ВКЛЮЧЁН»; `curl -s https://api.ipify.org`
   — адрес сервера.
4. Выключить: **o** в интерфейсе или `tuntop off`.

Защита от утечек (kill switch): `tuntop killswitch on` или **Esc** →
«Настройки» → «Защита». Пока VPN включён, трафик идёт только через
туннель; `tuntop off` снимает защиту.

Клавиши интерфейса — **?**; команды — `tuntop help`.

## Что важно знать

- Служба tuntop работает от администратора (root): она включает туннель,
  меняет маршруты и DNS, пока VPN включён, и возвращает их при выключении,
  остановке службы или после сбоя. Пока VPN выключен, сеть не трогается.
- tuntop обращается только к вашему провайдеру и его серверам: без
  телеметрии и сторонних сервисов. Для подписки передаётся идентификатор
  устройства, как в Happ.
- Сборка не подписана Apple: установщик снимает с программ пометку
  «загружено из интернета», поэтому macOS не спрашивает разрешения.

## Обновление

Новый архив — те же шаги 2.1–2.3. Подписки и настройки сохраняются, VPN
после обновления выключен.

## Если что-то пошло не так

- Журнал службы: вкладка **5** в `tuntop` или файл `/var/log/tuntopd.log`.
- Остановить службу (VPN выключится, маршруты и DNS вернутся):

  ```bash
  sudo launchctl bootout system/org.tuntop.tuntopd
  ```

  Запустить снова: `sudo launchctl bootstrap system
  /Library/LaunchDaemons/org.tuntop.tuntopd.plist`.
- Сайты не открываются по именам после сбоя:
  `sudo networksetup -setdnsservers Wi-Fi Empty` (имя подключения — из
  `networksetup -listnetworkserviceorder`).

## Удаление

Из папки архива:

```bash
sudo bash uninstall-macos.sh            # подписки останутся
sudo bash uninstall-macos.sh --purge    # вместе с подписками
```
